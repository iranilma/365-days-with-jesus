## 3. Strict Authoring Rules for Days 8–365

1. **Zero Paraphrasing as Direct Quotes**: Never write a summary or personal paraphrase inside quotation marks as if it were the biblical text.
2. **Accurate Chapter & Verse Numbers**: Double-check chapter and verse boundaries.
3. **Consistent God Names in WEB**: The WEB Old Testament renders the Tetragrammaton as *Yahweh*. In devotional reflections, *Lord*, *Father*, and *God* can be comfortably used to aid personal quiet-time prayer.
4. **Flagging Mechanism**: Any verse whose exact wording cannot be confirmed against the WEB canonical text must be marked with `[FLAG: SCRIPTURE_UNVERIFIED]` before production deployment.
